 🌱 Automated Plant Disease Detection Using ConvNeXt

## 📌 Project Overview

An AI-based plant disease detection system that identifies plant diseases using crop leaf images.

The system uses ConvNeXt architecture and progressive transfer learning to classify plant diseases and generate diagnostic reports.

## 🎯 Objectives

- Identify plant diseases using leaf images.
- Apply deep learning for image classification.
- Support early disease identification.
- Generate diagnostic reports to assist farmers.

## 🛠️ Technologies Used

- Python
- Deep Learning
- ConvNeXt
- TensorFlow / Keras
- Image Processing
- Progressive Transfer Learning

## ⚙️ Project Workflow

1. Collect plant leaf images.
2. Preprocess input images.
3. Train the ConvNeXt-based model.
4. Predict plant diseases.
5. Generate diagnostic reports.

## ✨ Key Features

- Image-based disease identification.
- Deep learning classification.
- Image preprocessing.
- Diagnostic report generation.
